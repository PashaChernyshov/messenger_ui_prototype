# Messenger UI Prototype

Flutter-прототип корпоративного мессенджера с XMPP-интеграцией, темной минималистичной темой и поддержкой личных и групповых чатов.

## Что внутри

- Личные чаты и групповые MUC-комнаты.
- Подключение к XMPP-серверу через TCP/5222, STARTTLS и SASL PLAIN.
- Загрузка roster, bookmarks и истории через MAM, если сервер это поддерживает.
- Отправка и получение личных и групповых сообщений.
- Голосовые сообщения и видеокружки с мгновенным появлением в чате и индикатором прогресса отправки.
- Запись видеокружков через камеру с переключением камер, улучшенным качеством фронтальной камеры и pinch-to-zoom.
- Настройки интерфейса, сообщений, микрофона и XMPP в едином темном стиле.
- Профиль пользователя, контакты, группы, история звонков и локальные демо-данные.

## Стек

- Flutter
- Dart
- Provider
- SharedPreferences
- XMPP через собственный сервисный слой
- `record` для работы с микрофоном
- `camera` для съемки видеокружков
- `ffmpeg_kit_flutter_new` для обработки видео
- `video_player` для воспроизведения видеокружков

## Запуск

```bash
flutter pub get
flutter run
```

Для проверки кода:

```bash
dart format lib
dart analyze lib
```

Прямое XMPP-подключение через TCP/5222 работает для desktop/mobile-сборок. Для web потребуется отдельный слой WebSocket/BOSH, потому что браузер не поддерживает прямое TCP-подключение.

## Структура проекта

```text
lib/
  main.dart
  app/
    state/
    theme/
  core/
    ui/
    widgets/
  features/
    calls/
    chat/
    contacts/
    groups/
    profile/
    settings/
    shell/
    xmpp/
```

Проект организован по feature-first подходу:

- `domain` - модели предметной области;
- `data` - репозитории и источники данных;
- `presentation` - экраны, виджеты и view models.

## Основные модули

### `app`

Глобальное состояние приложения и тема. `AppState` связывает UI, чаты, контакты, группы, настройки и XMPP-сервис.

### `features/xmpp`

Низкоуровневый XMPP-сервис: подключение, авторизация, roster, bookmarks, MUC, MAM, входящие и исходящие сообщения.

### `features/chat`

Экран чата, сообщения, реакции, черновики, вложения, голосовые сообщения и видеокружки.

### `features/settings`

Общие настройки приложения: интерфейс, отображение сообщений, выбор и тест микрофона, XMPP-конфигурация и статус подключения.

### `features/shell`

Основная оболочка приложения: список чатов, навигация, меню пользователя и действия с чатами.

## Важно

Учетные данные XMPP не должны храниться в репозитории. Они вводятся пользователем в настройках приложения и сохраняются локально.

Это актуальная версия прототипа. В репозитории лежит один Flutter-проект без старой версии и без дополнительных вложенных проектов.
